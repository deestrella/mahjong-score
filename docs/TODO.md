# 既知の課題・改善アイデア

## 運用
- [ ] Gemini 無料枠の1日上限(全員の合計)。人数が増えたら DAILY_LIMIT とモデルを見直す
- [ ] モデルの提供終了に備え、`FALLBACK_MODELS` を定期的に確認する(gemini-2.5-flash は新規提供終了済み)
- [ ] 合言葉が漏れたら PASSPHRASE を変更する。仲間への伝え方を決める
- [ ] 読み間違いの報告窓口(Google フォーム or GitHub Issues)

## 読み取り
- [ ] Gemini の読み取り精度(筒子・索子の数え違い)。実物の牌の写真でテストを増やす
- [ ] 読み取り結果の牌を画面上でタップして直せる UI(いまは文字で修正)

## ルール・計算
- [ ] ルール設定(切り上げ満貫、連風牌の符、ダブル役満、喰いタンなし)を選べるようにする
- [ ] 天和・地和・人和・流し満貫
- [ ] 役がないとき(sum=0)の表示を「役なし」にする(いまは前の翻数が残る)
- [ ] 役判定のテストを増やす(チャンタ/純チャン、三色同刻、小三元、九蓮宝燈など)

## 体験
- [ ] ホーム画面に追加できるアプリ化(manifest とアイコン)
- [ ] 点数の履歴
